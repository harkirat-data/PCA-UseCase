# PCA Implementation

This repository contains a simple implementation of Principal Component Analysis (PCA) using Python and Scikit-learn.

## Topics Covered
- Data Loading
- Data Standardization
- PCA
- Explained Variance
- Explained Variance Ratio
- Data Transformation
- 2D Visualization of Principal Components

## Libraries Used
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Plotly

## Dataset
Breast Cancer Wisconsin Dataset (`sklearn.datasets.load_breast_cancer`)
